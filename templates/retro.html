RETROSPECTIVE

Sprint 3 — Checkout consolidation

The squad shipped the single-page checkout behind a feature flag and ran the first funnel comparison. This retrospective captures what worked, what did not, and the actions we are taking into sprint 4.

Completed 2026-08-11 Facilitator: J. Park Duration: 2 weeks

Metrics

38% abandonment, down from 68%
12 stories completed of 14
2 production incidents
94% test coverage on checkout

Timeline

  • Jul 28
    Sprint kickoff. Agreed on the funnel metric and the cohort definition so the before-and-after comparison would be apples to apples.
  • Aug 01
    Guest checkout merged. Email-only identity shipped behind the flag; the post-purchase account prompt was deferred to sprint 4.
  • Aug 05
    Express payments enabled. Apple Pay and Google Pay went live for a ten-percent canary cohort after the Payment Request API check passed.
  • Aug 08
    Funnel comparison. The first full-cohort read showed abandonment at 38%, beating the 40% target ahead of schedule.
  • Aug 11
    Retrospective. Reviewed the two incidents and agreed the action items below.

What went well

  • Guest checkout removed the largest single drop-off in the funnel
  • The persistent order summary eliminated surprise-total complaints
  • Feature-flag rollout let the team compare cohorts without a big-bang release

What went wrong

  • Two incidents from a shared draft-order write path that raced on refresh
  • Two stories slipped because the express-payment integration was under-scoped
  • The funnel event schema changed twice, delaying the comparison by a day

Learnings

A single-page flow with a visible summary is worth more than the sum of its parts. The abandonment drop came mostly from the guest path, but the summary removed a whole class of end-of-funnel complaints.

The draft-order race shows that progressive disclosure still needs a single writer. Next time, define the write path and its idempotency key before wiring the UI.

Action items

  • Add an idempotency key to the draft-order write path
  • Freeze the funnel event schema before the next rollout
  • Re-scope express payments to include a regional wallet for the EU launch
  • Ship the post-purchase account prompt as an inline panel
